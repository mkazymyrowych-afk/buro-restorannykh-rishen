# Бюро ресторанних рішень — лендинг

Односторінковий сайт для бренд-шефа Дмитра: відкриття закладів харчування під ключ по всій Україні.

## Структура
- `index.html` — увесь сайт (HTML + CSS + JS в одному файлі, без збірки)
- `img/` — фото шефа, страв, закладів, кухні; логотип у `img/logo/`
- `video/kitchen.mp4` — відео кухні перед відкриттям
- `brief-fastfood.md` — бриф клієнта, фідбек посередника і карта фото

## Блоки сторінки
Перший екран → «Розпаліть свій заклад» (інтерактивний розрахунок з фото-фасадами `img/venues/`) → Заклади → 6 помилок на старті → Для кого → Про шефа → 4 етапи (Іскра → Розпал → Жар → Вогонь) → Як це буде (з відео кухні) → Формати → Франшиза чи свій заклад → Меню → Питання → Заявка

## Що ще треба
- Заявка формує готовий текст і відкриває чат із шефом у Telegram (`t.me/Dima_Brss?text=…`); за бажання клієнта можна підключити Telegram-бота
- Фасади в `img/venues/` — згенеровані концепти (на сайті підписані «Концепт для прикладу»), не реальні заклади
- Перевірити Telegram клієнта (`t.me/Dima_Brss`) і додати Instagram/TikTok, коли з'являться
- Прізвище клієнта і назву його ресторану на сайті не вказувати без його згоди

## Локальний перегляд
Відкрити `index.html` у браузері або запустити `python -m http.server` у цій папці.
